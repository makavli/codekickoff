# Your first week

The commands and habits that matter most, checked against Claude Code's documentation in November 2026. `/help` lists everything.

## The five to start with

- **`/usage`**: how much of your plan's allowance is left, and what this session cost.
- **`/clear`**: a fresh conversation for a new task. Old context costs you on every message; clear it between tasks.
- **`/plan`**, or **Shift+Tab** until it says plan: Claude thinks and proposes before it edits anything. Use it for anything bigger than a small fix.
- **`/rewind`**: go back to an earlier point when a change went wrong.
- **`/effort`**: more thinking for one hard problem; set it back after.

## The rest of the week

- **`/compact`**: shorten a long conversation into a summary, when you must keep going on the same task.
- **`/resume`**: pick up a past conversation.
- **`/model`**: switch model; the choice is saved as your default.
- **`/memory`**: see and edit what Claude remembers (`CLAUDE.md` and auto memory).
- **`/init`**: write a `CLAUDE.md` that describes this project, so every session starts knowing it.
- **`/agents`**: the helpers you have, such as the four CodeKickoff set up.
- **`@file`** in a message points Claude at a file; **`!command`** runs a shell command yourself.
- **Esc** stops Claude mid-answer, so you can steer.

## Habits that save the most

1. **One task per conversation.** Say what "done" looks like in your first message.
2. **Ask for a plan first** on anything that touches many files.
3. **Read what it changed** before you accept a large edit; ask "why" whenever you are unsure.
4. **Keep `HANDOFF.md` current.** A new session reads it and carries on, so you can clear without losing the thread.
5. **Fewer plugins.** Each one rides along on every message. Install what you use, remove what you do not.
6. **Never paste a password or key** into a message or a file Claude will commit.
